I write bots that watch the chain and report back in Telegram.
Buy alerts, wallet trackers, group managers. Most of it runs on a VPS,
talks to a database, and has to keep working when I'm not looking.

I also port code between Python, TypeScript and JavaScript.
When a project outgrows one language, I move it without changing what it does.

**How I work:** I build with AI coding agents, and I'm open about it.
They write a lot of the code. I decide what gets built, review what comes back,
test it against real chains and real users, and fix what breaks in production.
Right now I'm going deeper into agents: how they plan, use tools, and fail.

A lot of my work is private, so this profile is thin for now.
I'm moving cleaned-up versions of it into public repos.

### What I've built

**Buybot**
Posts a message to a Telegram group every time a token is bought on-chain.
Reads swap events, formats them, stores state in Postgres.

**Tracking bot**
Follows wallets and tokens, sends an alert when something moves.

**Telegram manager bot**
Handles the boring parts of running a group: moderation, spam, verification.

**Private projects**
Blockchain and automation work for clients. I can talk about it, not show it.
